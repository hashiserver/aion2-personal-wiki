Global版のAsia向けPvE厳選候補です。**武器・ガーダーの戦闘速度と武器ダメージ増幅**を先に確認し、リングは**主力スキル+1で特化Lv16／20に届くか**も見てください。[[source:gear-global-roll-pool]]

## Asia向けの厳選候補

Globalの通常抽選で確認できる候補から、チャンターの火力・支援用途を基準に優先度を整理しました。実際に付く効果は装備ごとのプレビューを確認してください。[[source:gear-global-roll-pool]]

| 部位 | 優先 | 妥協候補 |
|---|---|---|
| 武器 | 戦闘速度・武器ダメージ増幅 | 威力・ダメージ増幅。対人兼用なら状態異常的中も候補 |
| ガーダー | 戦闘速度・武器ダメージ増幅 | 威力・ダメージ増幅。対人兼用の状態異常的中は下の例を参照 |
| ヘルム | 強打・攻撃力増加 | 攻撃力。耐久が必要なら受ける治癒量 |
| ショルダー | クリティカル ダメージ増幅・強打 | 攻撃力・防御力増加 |
| トップス | ダメージ増幅 | 完璧・攻撃力。耐久なら防御力増加 |
| グローブ | 戦闘速度 | 完璧・攻撃力 |
| ボトムス | 攻撃力増加・ダメージ耐性 | 完璧・攻撃力 |
| シューズ | 移動速度 | 完璧・攻撃力 |
| マント | 攻撃力増加・強打 | 攻撃力。耐久ならクリティカル ダメージ耐性 |
| ネックレス | 戦闘速度・威力 | 正確・攻撃力 |
| イヤリング×2 | 威力・移動速度 | 正確・攻撃力 |
| リング×2 | 特化に届く主力スキル+1。通常ステータスなら威力・正確 | 攻撃力・命中 |
| ブレスレット | 装備ごとの固定効果・抽選候補を確認 | 深淵のブレスレットは個別の候補から選ぶ |

マントの「完璧」は、通常抽選の候補とバクロンのマントでは確認できません。[[source:gear-global-roll-pool]][[source:gear-global-vacron-cloak]]

## PvPに移行するとき

**PvP上位者の部位別採用率は未確認**のため、現在のPvE装備を一括で調律せず、命中・状態異常・耐久の不足を対戦内容で判断します。

- 部位ごとの出現候補は[Global版の魂刻印データ](https://wikily.gg/ja/aion-2/enhancement/soul-binding)で照合できます。
- 4枠のステータス以外に、**主力スキル+1**で必要特化Lvに到達する場合は優先順位が変わります。
- [PvEとPvPの共通調整基準](/gear/)も参照。

## PvP兼用ガーダーの具体例

**戦闘速度・威力・状態異常的中・武器ダメージ増幅**は、状態異常を重視する場合の兼用例です。火力を優先するなら、状態異常的中の枠ではダメージ増幅も候補にできます。[[source:gear-global-roll-pool]]
