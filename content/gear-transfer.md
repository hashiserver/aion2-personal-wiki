**結論：同じ部位の低ILの唯一（金）装備に良い通常の魂刻印が付いていれば、そこを継承元として強化し、上位の唯一装備に移すことができます。** 一方、良い魂刻印が付いているのが**上位の継承先**なら、普通に継承するとその良い効果が置き換わるため要注意です。[[source:gear-transfer-jp-soul]][[source:gear-transfer-tw-official]]

## まず判断：どちらに良オプションがある？

| 持っている装備の状況 | おすすめ | 理由・注意 |
|---|---|---|
| 低IL唯一の**継承元**に良い魂刻印 | **低ILを先に強化→上位に継承** | 通常の魂刻印の種類と値、強化段階・突破を移せる |
| 高IL唯一の**継承先**に良い魂刻印 | **その装備を直接強化**が安全 | 通常の別装備からの継承では、継承先の良オプションが上書きされる |
| 高ILの**ワンド／ガーダー**に良い魂刻印 | **魂魄の武器／ガーダーを強化→継承**も候補 | 固定魂刻印の魂魄装備を元にすると、継承先の魂刻印を残して強化のみ移せるという日本語攻略例。必ず継承プレビューで確認 |
| 両方に良い魂刻印 | **継承前に比較** | 2つの良いライン群を単純合成できる仕組みではない。基本は元のラインで置き換わる |
| 伝承（青）・希少（緑）から上位へ | **通常の継承対象外** | 唯一（金）同士の継承を基本とする |
| 魂結束で5本目などを追加済み | **継承前に慎重に判断** | 魂結束で増やした追加ラインは通常継承されない |

通常の魂刻印は、継承元→継承先へ移ります。**「良いオプションがある装備を残す」のではなく、実際に継承結果の画面で残るラインを見て選ぶ**のが重要です。[[source:gear-transfer-jp-soul]][[source:gear-transfer-jp-cost]][[source:gear-transfer-global-guide]]

## 実例：チャンターのガーダー

たとえば、高ILのガーダーに **戦闘速度／威力／状態異常的中／武器ダメージ増幅** が付いているとします（PvP兼用の例）。

| 方法 | 強化段階 | 最後に残る魂刻印 |
|---|---|---|
| その高ILガーダーを直接+15にする | 高ILの強化費用が必要 | **今の良い4項目を維持** |
| 低ILで**同じ良い4項目**のガーダーを+15→継承 | 低ILの強化費で済む | **継承元の良い4項目を引き継げる** |
| 低ILで**悪い4項目**のガーダーを+15→通常継承 | 安く強化できる | **悪い4項目で上書きされる可能性** |
| 魂魄のガーダー（固定魂刻印）を+15→継承 | 安く強化できる可能性 | 日本語攻略では**継承先の良い4項目を維持**する例。実行前のプレビューが必須 |

3行目が特に危険です。**同じ部位なら何を元にしても良いわけではありません**。固定魂刻印の魂魄装備を利用する方法は第三者攻略で紹介された特殊例で、すべての装備に一般化しないでください。[[source:gear-transfer-jp-cost]][[source:gear-transfer-jp-soul]]

## 強化費用の比較（唯一+0→+15）

| 継承元／直接強化する装備 | 推定ギーナ（平均） | 判断 |
|---|---:|---|
| IL36の唯一装備 | 約531万 | 同部位の安い継承元候補 |
| IL45の魂魄 武器・ガーダー | 約660万 | 継承先の魂刻印を残したい場合の候補 |
| IL54の唯一装備 | 約796万 | アクセサリーの継承元候補 |
| IL70の唯一装備 | 約1,030万 | ほかの候補がない場合 |
| IL86の唯一装備 | 約1,263万 | 良い魂刻印を直接保持したい場合 |

**IL36とIL86の差は平均約732万ギーナ**。Aion2Dataの別試算も約731万ギーナの節約を示します。成功率や購入費、継承石、調律費などは含まず、**必ずその額が節約できるという意味ではありません**。[[source:gear-transfer-jp-cost]][[source:gear-transfer-global-cost-calculator]]

## 継承で移るもの・移らないもの

| 要素 | 継承 | 注意 |
|---|---|---|
| 強化段階（+N） | 基本的に移る | 上位装備自体のILは変わらない |
| 突破段階 | 基本的に移る | 対象装備・段階上限を確認 |
| **通常の魂刻印オプション** | **移る／継承先を置換** | 継承元の方がライン数が多いと一部抽選になる場合あり |
| 魂刻印の能力値 | 移るが範囲補正あり | 継承先で取れる最小・最大値に収まる |
| 魂結束で追加したライン | **移らない** | 高価な魂結束は最終装備に |
| 魔石・霊石・神石（テオストーン） | **移らない** | 最終装備で設定し直す |
| 潜在力 | **移らない** | 乗り換えを見込んで投資する |
| 継承元の装備本体 | **消費される** | 後から取り戻せないため確認必須 |

魂刻印の枠数が異なる場合、**継承元が多いとランダムな一部だけが移り、継承先が多いと余った枠には継承先のラインが残る**ことがあります。台湾公式でもこの処理が説明されています。[[source:gear-transfer-tw-official]][[source:gear-transfer-global-guide]]

## 実行前のおすすめ手順

1. **最終的に使う上位装備を決める**：装備等級・部位・武器種・ILを比較する。チャンターのワンド→ワンド、ガーダー→ガーダーのように対応するものを用意。
2. **継承元を選ぶ**：良い魂刻印を移したいなら良オプの低IL金装備。継承先の良オプを残したい武器・ガーダーでは、魂魄装備の特殊例を検討。
3. **継承元の強化を進める**：+15にするまでのギーナと強化石を、直接高ILに使う場合と比較。必要なら突破も確認。
4. **統合強化→継承**を開く：受け取る装備（最終装備）と、消費する装備（継承元）を間違えない。
5. **継承のプレビューを確認**：残る魂刻印4項目、数値、強化・突破段階、必要な継承石・ギーナ、成功率、対象・回数条件を全部確認。ひとつでも予想と違えば実行しない。
6. **継承後に仕上げる**：最後に調律や魂の書で仕上げ、魂結束、魔石・神石・潜在力などの移らない育成を行う。[[source:gear-transfer-jp-cost]][[source:gear-transfer-global-guide]]

## 地域・仕様差の注意

| 情報源・対象 | 内容 | 扱い |
|---|---|---|
| 台湾公式（2026-10-13更新） | 同部位・同等級、通常魂刻印の継承、強化失敗補正、成功率100%・回数制限なし。さらに唯一→英雄の上級継承も記載 | **台湾版公式**。日本・Globalにそのまま適用しない |
| Global第三者ガイド（2026-10-28更新） | 唯一装備の継承石1〜2個、成功率100%、ギーナ不要と案内 | **Globalの第三者記載**。公式確認済みではない |
| 別の日本語攻略 | 成功率やシーズン回数制限について異なる説明あり | **矛盾あり**。現行ゲーム画面の表示を優先 |
| 魂魄武器・ガーダーの特殊ルート | 固定魂刻印からの継承なら先の良オプを保持するという攻略例 | **第三者の実践例**。実行前のプレビュー必須 |

さらに、台湾版で案内される**唯一→英雄の上級継承は日本・Global版で利用できると確認できていません**。区別してください。[[source:gear-transfer-tw-official]][[source:gear-transfer-global-guide]][[source:gear-transfer-conflict-guide]]
